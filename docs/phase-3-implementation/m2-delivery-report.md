# تقرير تسليم M2

التاريخ: 2026-11-10. الفرع: `codex/m2-intent`؛ الأساس: `codex/m1-guard`. بدأ بعد نجاح CI لكود M1 في 228ee31 وتحديث تقريره في 0338c09. هذا التقرير وصف عربي جاهز لطلب السحب المسودة لدى Claude.

## الإصدارات المثبتة

لم تتغير مصفوفة M0: AGP 9.5.1، Gradle 9.6.0، Kotlin 2.4.21، KSP 2.3.13، Hilt 2.60.1، Coroutines 1.11.0، Room 2.8.5، Kover 0.9.11، JUnit 4.13.2، AndroidX Test Runner 1.7.0، Espresso 3.7.0. Node 22.23.4 وnpm 10.9.9 في الحاوية، ولا وسيط بعد.

## أوامر الاختبار

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export GRADLE_USER_HOME="$PWD/.cache/gradle"
export ANDROID_USER_HOME="$PWD/.cache/android"
export TMPDIR="$PWD/.cache/tmp"
./gradlew build test lint :core:guard:koverVerify
./gradlew verifyNoNetwork
```

لإعادة الاختبار السلبي، أنشئ init script مؤقتاً داخل .cache فقط:

```groovy
allprojects {
    afterEvaluate {
        if (path == ':core:intent') {
            dependencies.add('implementation', 'io.grpc:grpc-api:1.69.1')
        }
    }
}
```

ثم شغّل `./gradlew verifyNoNetwork --offline --init-script .cache/no-network-negative.init.gradle`. المتوقع خروج غير صفري برسالة `Network dependency forbidden in :core:intent: io.grpc:grpc-api`؛ هذا فشل مقصود للتحقق من القاعدة. لا تستخدم هذا init script في البناء العادي. نجح التحقق السلبي فعلاً خلال ثانية، ثم نجح البناء العادي الأخير خلال 4 ثوانٍ.

## قرارات اتخذتها

- نص الملاحظات وتعديل الرسالة بيانات حتى لو احتوى أسماء أو أوامر متعددة، لأن مثال الملف يتطلب حفظ `Call Nikos, 5 p.m.`. أما الأوامر التنفيذية التي تطلب مستلماً مسمى أو خطوات متعددة فتعيد null. البديل رفض الأسماء داخل متن الملاحظة يناقض المثال الملزم.
- تُستهلك مسافة فصل واحدة بعد النقطتين أو كلمة to كجزء من صيغة الأمر؛ كل ما يليها يُحفظ حرفياً، بما فيه المسافات الإضافية والأسطر والترقيم. لا trim لمتن النص. النص الفارغ أو المكون من مسافات فقط غير مطابق.
- القيم العددية تعاد كنص عددي ذي معنى، بينما متن النص لا يمر بالتطبيع مطلقاً. الأعداد الإنجليزية تدعم الوحدات والعشرات والمئات والآلاف والكسر المنطوق رقماً رقماً. لا تُخمن الصيغ غير المكتملة أو الكسور من نوع .5، ولا تحوّل سالباً إلى موجب عند إزالة الترقيم؛ تعود إلى المخطط الوهمي لاحقاً عبر null.
- علامات الترقيم الفاصلة تتحول إلى فراغات في المطابقة لمنع دمج `1,5` إلى `15`. النقطة بين رقمين تبقى نقطة عشرية. الفاصلة العليا في What's تُزال ليتطابق القاموس.
- قاعدة الشبكة تشمل guard وintent وprobes، وتشمل classpaths الاختبار أيضاً. في وحدتي JVM توجد قائمة مجموعات معروفة محدودة، إضافة إلى منع أسماء مكتبات النقل الشائعة؛ إضافة مجموعة جديدة تتطلب مراجعة التغيير في القاعدة. أدوات بناء Gradle نفسها ليست اعتماديات تطبيق ولا تُفحص كعميل إنتاجي.
- FakePlanner يعيد نتيجة اختبار جاهزة، ويدعم تأخيراً قابلاً لإلغاء coroutine، ولا يحتفظ بنص الطلب أو يسجله. لا يوجد ClaudePlanner أو API للنموذج.

## ما لم يُنفذ والتعارضات

لا أدوات تنفيذ ولا مخطّط شبكي ولا نشر. لا عائق بناء باقٍ في M2، ولا حزم نظام جديدة. لم تُعدّل الوثائق المحمية؛ الملف حاسم ولم يلزم الرجوع إلى v12 أو draft4، ولا تعارض جديد مثبت معهما. لا سلوك Android جديد في هذه الوحدة؛ ما يتعلق بربطها على جهاز بتاريخ 2026-11-10 «يُثبت ميدانياً».

## إصلاحات المراجعة 2026-11-10

- **2-1 — تم:** تُوحّد رموز الشرطة والسالب قبل إزالة علامات الترقيم، وتُرفض السوالب الرقمية والمنطوقة بما فيها `Volume −10` و`Volume -one`. تبقى الأعداد المركبة مثل `twenty-five` والمحتويات الحرفية للملاحظات كما هي. اختبار `negativeSymbolsAndSpokenNumbersNeverBecomePositiveCommands` فشل قبل الإصلاح ويغطي تسعة رموز وأربعة قوالب وأعداداً منطوقة وعشرية.
- دمج M1 شمل تعريف `ToolSpec.kind` الإلزامي؛ حُدّث تعريف أداة المخطّط الوهمي في الاختبار إلى `SYSTEM_NO_DATA`. حُلّ تعارض Gradle بإبقاء فحص Maven وفحص الملفات واختباراته معاً.
- التحقق النهائي: نجح `./gradlew build test lint koverVerify` محلياً مع اختبارات الحارس والمصنّف وفحص الاعتماديات الموروث، دون تعطيل اختبار أو lint.
- متابعة **2-1:** وُسعت الحالات إلى 13 رمزاً، بما فيها `➖` و`˗` والسالب العلوي والسفلي. كشف الاختبار أن السالب الثقيل `➖` كان يُحذف أيضاً؛ أصبح التطبيع يشمل أسماء Unicode التي تحتوي `MINUS` مع فئة الشرطات قبل فحص السالب. فشل الاختبار الموسع قبل التعديل ثم أُعيدت الفحوص، مع بقاء نص الملاحظة الأصلي والأعداد المركبة محفوظين.
- **N-1 — تم:** حُصر فحص السالب والكسور غير المكتملة في المعامل العددي لقوالب المؤقت والصوت والإرجاع والسرعة، مع إبقاء تطبيع ترقيم الأوامر الثابتة. أضيف اختبار `hyphenatedFixedCommandsKeepPunctuationNormalization` للأوامر `Volume-up` و`Flashlight-on` و`Do-not-disturb-on`، وبقيت حالات `-one` و`−10` وجميع رموز السالب السابقة والأعداد المركبة وحفظ الملاحظات. فشل الاختبار الجديد على التنفيذ السابق ثم نجح بعد الإصلاح. نجح `./gradlew build test lint koverVerify` محلياً بـJDK 17، ونجحت اختبارات المصنّف الثمانية دون فشل أو تخطٍ. تعثرت محاولة أولية بتنزيل اعتماد اختبار بـHTTP 429، ثم نجحت الفحوص بمخزن الاعتماديات المحلي السابق دون تعطيل أي فحص.
