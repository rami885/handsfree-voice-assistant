# تقرير إصلاح تجربة الاستخدام الميداني في MoVA Lab

**التاريخ:** 2026-11-12. **الأساس:** `774a380`. **الفرع:** `codex/probes-field-ux-fixes`.

- **D — الرجوع:** يسجّل `ProbeActivity` callback عبر `OnBackInvokedDispatcher` على API 33+ عند عرض تجربة فقط، ويلغيه في القائمة وعند تدمير النشاط. بقي مسار API 31–32. صار الزر `← Back to experiments`. اختبارات API 31 و32 و33 و36 تغطي الرجوع، والدوران، واستعادة الشاشة بعد إعادة إنشاء العملية.
- **A — النافذة:** خلفية معتمة تملأ نافذة الجلسة، ونص فاتح أو داكن بحسب الوضع. اختُبرت العتامة والأبعاد والتباين. بقي حجب تفاصيل السجل عند القفل باستخدام `substringBefore(":")`، وله اختبار انحدار.
- **B — الاختيار:** فتح الشاشة يستدعي `select(id)` ويسجّل `screen / selected` دون تشغيل. التبديل يوقف السابقة بسبب `screen_changed` قبل تغيير المعرّف، ويغلق جلستها ويعيد خيارات التجربة إلى القيم الافتراضية. اختُبر إلغاء التشغيل والتصدير الناجح إلى JSON بمعرّفات التجارب الصحيحة، وتحديث الإشعارات وحالة التعرّف. الرجوع للقائمة وإعادة عرض التجربة نفسها يبقيان الاختيار والتشغيل.
- **C — T1a:** يسجّل إعداد `voice_recognition_service`، ومطابقته لخدمة التطبيق، ومكوّنات خدمات التعرّف الظاهرة فقط. يُسجّل `unset` أو `unreadable` عند غياب القيمة أو رفض قراءتها، وتبقى المطابقة حينها `unknown`. التفسير معلّم `manual_validation_required`. اختُبرت القيم والمطابقة والاستثناء وبيانات الخدمة في الـmanifest. الخدمة معلنة للتصدير مع الإجراء والفئة والبيانات الوصفية؛ أُضيف `selectableAsDefault="true"` صراحةً، وفق [تعريف AOSP](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/core/res/res/values/attrs.xml).

حُدّث الدليل العربي لشرح الرجوع والاختيار، مع إبقاء `START` للتشغيل، وخطوة البحث عن محرك التعرّف في إعدادات Samsung وتسجيل ما وُجد في `Manual observation`.

نجح محلياً بـJava 21:

```sh
./gradlew build test lint koverVerify assembleAndroidTest
```

نجحت اختبارات وحدة `probes` عشر مرات متتالية، مع إعادة تنفيذ `:probes:testDebugUnitTest --rerun :probes:test` في كل مرة: **138 اختباراً لكل جولة، أي 1380 تنفيذاً، دون فشل أو أخطاء أو تخطٍّ**. إعداد المشروع يوفّر اختبارات الوحدة لنسخة Debug؛ جُمّعت Release ضمن `build`.

تحتاج محاكاة API 36 في Robolectric إلى Java 21؛ حُدّث CI، وأُضيف فتح نطاقَي JVM اللازمين لها. يوجد استثناء lint موضعي موثّق لـ`GestureBackNavigation` على مسار `onBackPressed` القديم فقط، لأن الكشف يبلّغ عن التعريف رغم حارس API. بقيت بوابات الفحص والاختبارات مفعّلة.

لم تُضف أذونات أو اعتماديات؛ لا `INTERNET` ولا مكتبة شبكة ولا Accessibility. جُمّعت اختبارات Android ولم تُشغّل على جهاز أو محاكي محلي. السلوك الفعلي بعد الإصلاح على Samsung SM-S938B وAndroid 17، وظهور MoVA Lab ضمن محركات التعرّف، «يُثبت ميدانياً» (2026-11-12).
