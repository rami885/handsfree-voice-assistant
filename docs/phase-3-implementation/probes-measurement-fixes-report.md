# إصلاح قياسات probes قبل التجارب الميدانية

التاريخ: 2026-11-10. المرجع: مراجعة Codex للمسودة 5. الفرع: `codex/probes-measurement-fixes`.

- **T3:** خيار صريح `Screen-off measurement` بنافذة 15 ثانية، يبقي الالتقاط عند إطفاء الشاشة دون قفل تشغيل. الوضع العادي يبقى 3 ثوانٍ ويتوقف عند إطفائها. حاويات كل 1000 ms تسجل العينات وغير الصفرية وعدد قراءات PCM (`frames`) والقراءات ذات العينات غير الصفرية، مع الفصل قبل الإطفاء وبعده والحاويات الفارغة. تسجل لحظة الإطفاء ومدة التشغيل الفعلية و`endReason` و`stopRequest`؛ سحب الموافقة والمكالمة يطلبان الإيقاف فوراً في الوضعين. تُحفظ العدّادات كل ثانية لاستعادتها بعد فقدان العملية كـ`service_killed`؛ عند غياب لحظة النهاية يكون `durationMs=null` و`durationExact=false` و`durationLowerBoundMs` آخر مدة محفوظة، دون تخمين مدة دقيقة.
- **T4:** تسجل كل محاولة ونتيجتها، ثم المحاولات والنجاحات والمهل والإخفاقات ومعدل النجاح. الوسيط وp90 محسوبان للنجاحات فقط، ويظهران بجوار المعدل. ثوابت نجاح فتح المسار: **20 محاولة، نجاح ≥90%، والوسيط وp90 كلاهما أقل من 2000 ms**. المئين بطريقة أقرب رتبة؛ لا نجاح لنتيجة سريعة واحدة وسط 19 مهلة، ولا للقياس الخالي من النجاحات. وضوح الجمل ملاحظة مستقلة.
- **T6:** الثابت `MEDIA_SEARCH_WINDOW_MS=4000` من الاستدعاء الفعلي. النجاح يجمع `STATE_PLAYING` ومطابقة كل كلمات الاستعلام في العنوان أو الفنان دون حساسية لحالة الأحرف، للجلسة المرتبطة بالطلب وحدها. النتائج الأخرى: `no_session` و`unsupported` و`timeout_no_playing` و`playing_no_match`. يستمر ربط N-2، ولا يرسل controller طلباً دون إعلان الدعم وفق N-3؛ انتظار اكتشافه محدود بأربع ثوانٍ قبل نافذة الطلب. لا تكفي بيانات جلسة سابقة، وتُقبل بيانات جلسة باردة اكتُشفت بعد الطلب ضمن النافذة.
- **T10:** أضيف `read` و`send` بالصوت والأزرار عبر الحارس، مع تسجيل `Deny(LOCKED)` أو `Allow` وحالة القفل الآمن والقفل والمفتاح. القراءة المسموحة تحاول نطق ملخص آخر إشعار عند توفر الوصول وموافقته؛ عدم توفره نتيجة منفصلة. الإرسال يختبر تجهيزاً ولقطة تأكيد اصطناعية فقط دون تنفيذ إرسال. إطفاء المفتاح يحدّث السياق فوراً. لم يتغير بيان الأذونات، ولا يوجد إذن `INTERNET` في التطبيق.

حُدّث دليلا HTML وMarkdown. أضيف `measurements` ككائن في JSON وعمود JSON مقتبس في CSV، مع إبقاء `value` وتوافق قاعدة الأحداث الحالية. يشمل اختبار التصدير حقول التجارب الأربع. الصوت الخام لا يُحفظ.

نجح الأمر المطلوب كاملاً:

```sh
./gradlew build test lint koverVerify assembleAndroidTest
```

نجحت اختبارات `probes` الـ95 عشر مرات متتالية بالأمر `./gradlew :probes:testDebugUnitTest --rerun`، مع التحقق من تنفيذ المهمة فعلياً في كل جولة: **950 تنفيذاً، صفر إخفاقات، صفر أخطاء، صفر اختبارات متخطاة**. تغطي الاختبارات الحالات الأربع، وحدود المهلة وربط الجلسة، وموت الخدمة واستعادة العملية، وسحب الموافقات، ومسار أزرار T10، وظهور الحقول في CSV وJSON. لم يُعطّل أو يُستثنَ أي اختبار ولم تُخفف عتبة قائمة. نجح أيضاً فحص سلامة المستودع و`git diff --check`.
